## Parent

Part of #1 — [使用跨平台 Secure Storage 保護 Classroom Connection](https://github.com/mz038197/classroom-app/issues/1)。

## What to build

證明實際發行的 Windows 單一 EXE 能完成安全連線生命週期，並留下可核對的整合驗證結果與未驗證項目。

遵守母議題的 [Secure Storage ADR](https://github.com/mz038197/classroom-app/blob/master/docs/adr/0001-secure-storage.md) 與 [Classroom App Context](https://github.com/mz038197/classroom-app/blob/master/CONTEXT.md)。不變更 Router 兌換、Course Catalog 或 Session Model Allowlist API 契約。延續 node:test 與 dependency injection 慣例，核心測試優先使用既有 storage seam。

## Acceptance criteria

- [ ] 在真實 Windows 執行打包後的單一 SEA EXE，驗證 Nickname Redeem、同帳號跨行程加解密、Class Label／Nickname／Mode 恢復、Allowlist 判定、Copy Key、換堂與清除。
- [ ] 驗證 EXE 使用系統內建 powershell.exe，不依賴學生另外安裝 PowerShell 7 或原生擴充。
- [ ] 檢查正常保存、遷移與失敗／中斷路徑的磁碟資料不包含明文 API Key 或課堂身分；安全替換中斷後不恢復半筆連線或意外的舊課堂。
- [ ] 驗證金鑰不進入子行程命令列、暫存腳本、頁面、錯誤訊息、log 或安裝輸出；子行程异常受控失敗，不明文 fallback。
- [ ] 涵蓋舊明文遷移成功／失敗、刪除失敗、既有密文不可解後保留、Router 暫時離線、無／空 Allowlist，以及換堂與清除失敗的可觀察行為。
- [ ] 可用第二測試帳號時驗證其 DPAPI 身分無法直接解密另一帳號密文；記錄執行環境與結果，未執行的 Windows 或跨帳號案例明確標為未驗證。
- [ ] 既有模型路由、Copilot provider 保留、課堂安裝指令與其餘必要回歸測試維持通過；驗證 Encryption at Rest，不宣稱防止同一 Windows 使用者的 DPAPI／記憶體／剪貼簿存取。
