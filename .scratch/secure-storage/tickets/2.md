## Parent

Part of #1 — [使用跨平台 Secure Storage 保護 Classroom Connection](https://github.com/mz038197/VansPod/issues/1)。

## What to build

Windows 學生兌換後得到 Persistent Classroom Connection，直接讀取磁碟資料不會取得明文憑證或課堂身分，並能於同帳號重啟後恢復連線資料。

遵守母議題的 [Secure Storage ADR](https://github.com/mz038197/VansPod/blob/master/docs/adr/0001-secure-storage.md) 與 [VansPod Context](https://github.com/mz038197/VansPod/blob/master/CONTEXT.md)。不變更 Router 兌換、Course Catalog 或 Session Model Allowlist API 契約。延續 node:test 與 dependency injection 慣例，核心測試優先使用既有 storage seam。

## Acceptance criteria

- [ ] Windows 使用 DPAPI CurrentUser，透過系統內建 powershell.exe 的 .NET ProtectedData 加解密；不要求 PowerShell 7 或原生擴充。敏感輸入只透過 stdin 傳遞，處理 UTF-8 與輸出邊界；子行程失敗回傳受控錯誤，不將敏感資料放入命令列、暫存腳本、log 或錯誤訊息。
- [ ] Classroom API Key、Class Label 所需 Session metadata、Nickname 與 Mode 當作同一筆版本化資料加密；磁碟只保留可辨識的加密封裝，不能誤讀成舊明文格式。
- [ ] 保存遵循加密、驗證可解密、寫入受保護暫存資料、替換的順序；保存失敗或中斷不留下不完整的有效連線，不產生明文備份。
- [ ] 新兌換在沒有舊持久化連線、且 Windows 安全儲存不可用時可退回 Temporary Classroom Connection，不顯示專用模式警告；不能將既有明文當作 fallback。
- [ ] 同一 Windows 使用者重啟後可恢復金鑰、Session metadata、Class Label 與 Nickname；重新讀取 Course Catalog／Session Model Allowlist，不因 Router 暫時離線刪除憑證。Model Switch 的完整恢復由後續票處理。
- [ ] 區分不存在憑證、舊明文需遷移、密文不可解與儲存故障；既有密文解密失敗時保留但拒絕使用，要求重新兌換，新的成功兌換才安全取代。
- [ ] 以 storage fake 與儲存層測試驗證結果對上層的不透明性、重啟恢復、受控失敗及安全更新；驗證外部行為，不固定 PowerShell 命令字串或密文字節。
