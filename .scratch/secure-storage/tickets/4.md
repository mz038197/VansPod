## Parent

Part of #1 — [使用跨平台 Secure Storage 保護 Classroom Connection](https://github.com/mz038197/VansPod/issues/1)。

## What to build

讓學生重啟後恢復先前 Model Switch 選擇，同時以當時有效的 Session Model Allowlist 決定 Classroom 模型是否可用。

遵守母議題的 [Secure Storage ADR](https://github.com/mz038197/VansPod/blob/master/docs/adr/0001-secure-storage.md) 與 [VansPod Context](https://github.com/mz038197/VansPod/blob/master/CONTEXT.md)。不變更 Router 兌換、Course Catalog 或 Session Model Allowlist API 契約。延續 node:test 與 dependency injection 慣例，核心測試優先使用既有 storage seam。

## Acceptance criteria

- [ ] Model Switch 的 Native／Classroom 選擇與 Classroom Connection 一起加密保存；模式更新與儲存結果協調，失敗不留下不完整或未提交的有效狀態，不另外明文持久化。
- [ ] 重啟恢復連線後重新取得 Course Catalog 與 Session Model Allowlist；只有有效且非空 Allowlist 才能恢復 Classroom 模式。
- [ ] 儲存 Mode 為 Classroom 但啟動時清單缺失、明確為空或 Router 暫時離線時，画面與實際 Codex／Claude 上游安全處於 Native／不可用狀態，不送未允許的課堂模型，也不刪除憑證。
- [ ] Router 恢復後學生可重新載入資料並使用課堂模型；不以本機預設清單取代 Session Model Allowlist。
- [ ] 執行中曾成功取得的 Allowlist 維持既有暫留規則；明確空清單與缺清單不得冒充有效清單。
- [ ] 以 storage fake 驗證兩種 Mode 的保存與重啟、保存失敗、Router 離線與重載、缺清單／空清單，以及畫面與實際代理目標一致；既有模型路由與客戶端設定回歸測試通過。
