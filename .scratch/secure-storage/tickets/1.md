## Parent

Part of #1 — [使用跨平台 Secure Storage 保護 Classroom Connection](https://github.com/mz038197/VansPod/issues/1)。

## What to build

讓學生透過可替換的 Secure Storage 邊界建立並使用當次有效的 Temporary Classroom Connection，為後續 Windows 安全持久化提供整筆連線的儲存契約。

遵守母議題的 [Secure Storage ADR](https://github.com/mz038197/VansPod/blob/master/docs/adr/0001-secure-storage.md) 與 [VansPod Context](https://github.com/mz038197/VansPod/blob/master/CONTEXT.md)。不變更 Router 兌換、Course Catalog 或 Session Model Allowlist API 契約。延續 node:test 與 dependency injection 慣例，核心測試優先使用既有 storage seam。

## Acceptance criteria

- [ ] 沿用既有 storage 依賴注入邊界，將 Classroom API Key、Session metadata、Classroom Nickname 與 Model Switch 選擇收斂為同一筆連線紀錄；核心不直接依賴平台加密 API，介面可供未來敏感資料重用，但不新增 Discord 功能。
- [ ] 新 Nickname Redeem 成功後，Temporary Classroom Connection 可完成 Class Label 呈現、Course Catalog／Session Model Allowlist 載入、Model Switch、Copy Classroom API Key 及既有 Router 代理流程。
- [ ] macOS／Linux 尚無安全儲存 Adapter 時只使用行程內記憶體；不產生明文持久化，結束行程後無法恢復，正常 Temporary 狀態不顯示額外模式提示。
- [ ] Temporary Classroom Connection 可清除；無連線時不提供複製金鑰或課堂模型。API Key 不回顯於畫面、錯誤或安裝輸出。
- [ ] 以 storage fake 驗證兌換、複製、清除、模型切換與代理的可觀察行為；Temporary 狀態跨行程失效，既有路由與 provider 保留測試維持通過。
